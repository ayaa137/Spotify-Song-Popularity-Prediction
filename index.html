Project Overview

This project investigates how well Spotify song popularity can be predicted using measurable audio characteristics such as acousticness, danceability, energy, instrumentalness, loudness, speechiness, tempo, and valence.

The analysis combines exploratory data analysis with machine learning models, including Linear Regression, Random Forest, and Histogram Gradient Boosting. A key finding is that release year is a dominant predictor of popularity, showing the importance of temporal structure in the dataset.

Main Findings

Strong Year Effect

Release year has a strong positive relationship with popularity, with a correlation of approximately 0.862.

Audio Features Matter

Audio-only models still explain meaningful variation in popularity, but their performance is weaker than models including release year.

Best Model

Random Forest using audio features and release year achieved the best performance, with MAE = 6.695, RMSE = 9.534, and R² = 0.810.

Model Comparison Summary

The best-performing models were the non-linear ensemble models using both audio features and release year. Random Forest and Histogram Gradient Boosting performed almost identically, while Linear Regression also improved substantially when release year was included.
