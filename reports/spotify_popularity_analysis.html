Predicting Spotify Song Popularity Using Data Science and Machine Learning¶

Author: Aya Abdine

Project Overview¶

Music streaming platforms generate large amounts of data describing both songs and listener engagement. This project investigates whether measurable audio characteristics can help explain and predict the popularity of songs on Spotify.

Using a large historical dataset of Spotify tracks, the analysis explores relationships between song popularity and audio features such as danceability, energy, loudness, valence, tempo, acousticness, instrumentalness, liveness, and speechiness.

The project combines exploratory data analysis (EDA) with machine learning to identify important patterns and evaluate how accurately song popularity can be predicted from audio features alone.

Research Question¶

How well do Spotify audio features explain and predict song popularity?

Project Objectives¶

  • Explore the structure and quality of the Spotify dataset.
  • Analyze the distribution of song popularity.
  • Investigate relationships between audio features and popularity.
  • Examine how musical characteristics and popularity change over time.
  • Build and compare machine learning models for predicting popularity.
  • Evaluate model performance using appropriate regression metrics.
  • Identify the audio features that contribute most to popularity predictions.
  • Discuss the limitations of predicting popularity using audio features alone.

6.1 Distribution of Song Popularity¶

The distribution of the target variable is examined to understand how Spotify popularity scores are spread across tracks. Particular attention is given to the concentration of zero-popularity tracks and the overall shape of the distribution.

Finding: The popularity distribution shows a pronounced concentration at the lowest end of the scale. A total of 27,892 tracks (16.34% of the dataset) have a popularity score of exactly 0. Beyond this concentration, most popularity scores fall within the low-to-moderate range, while very high popularity scores are relatively uncommon. The mean popularity score is 31.4 and the median is 33. Overall, the distribution is not well described as simply right-skewed because of the substantial mass at zero and the broader concentration of non-zero scores across the middle of the scale.

7. Predictive Modeling¶

The exploratory analysis revealed that song popularity is strongly associated with release year, while individual audio features show weaker relationships after accounting for temporal trends. This section evaluates how well song popularity can be predicted using available numerical characteristics.

The modeling strategy compares a simple baseline with multiple machine learning approaches. Model performance is evaluated on unseen test data using MAE, RMSE, and R². This allows comparison between linear and non-linear predictive relationships.

7.1 Feature Selection and Train-Test Split¶

The target variable is popularity. Predictors include release year and selected numerical audio features. Identifier and text-based variables such as track name, artist name, and Spotify ID are excluded because they are not directly suitable for the current numerical modeling framework.

Training set shape: (136522, 10)
Test set shape: (34131, 10)

Training target mean: 31.44
Test target mean: 31.4

Split Validation¶

The dataset was divided into 80% training data and 20% test data, resulting in 136,522 training observations and 34,131 test observations. The mean popularity scores are nearly identical across the two subsets (31.44 for training and 31.40 for testing), indicating that the random split preserved the overall distribution of the target variable.

7.2 Baseline Model¶

Before fitting machine learning models, a simple baseline prediction is established. The baseline predicts the mean popularity score of the training set for every observation in the test set. More advanced models should outperform this benchmark to demonstrate meaningful predictive value.

Model MAE RMSE R²
0 Mean Baseline 18.564 21.875 -0.0

Baseline Interpretation¶

The mean baseline produces an MAE of 18.56 and an RMSE of 21.88 popularity points. Its R² is approximately zero, as expected for a model that assigns the same training-set mean to every test observation.

These values establish a reference benchmark for subsequent predictive models. A useful model should reduce both MAE and RMSE while achieving a positive R², indicating that it explains variation in song popularity beyond a constant mean prediction.

7.3 Linear Regression¶

A multiple linear regression model is fitted as the first predictive model. It uses release year together with the nine numerical audio features to estimate song popularity. The model provides a transparent benchmark for assessing whether linear relationships can improve substantially over the mean baseline.

The result also reinforces the earlier exploratory finding that raw relationships between audio characteristics and popularity are partly confounded by historical change. Therefore, strong performance from the full model should not be attributed to audio features alone.

7.4 Random Forest Regression¶

Random Forest regression is used to capture non-linear relationships and interactions that may not be represented adequately by linear regression. Two versions are evaluated: an audio-only model and a full model that additionally includes release year. This preserves the earlier comparison between musical characteristics and temporal information.

Because the dataset contains more than 170,000 observations, the models use a controlled number of trees and parallel processing to balance predictive performance and computational efficiency.

Model MAE RMSE R²
0 Random Forest - Audio Only 10.674 14.084 0.585
1 Random Forest - Audio + Year 6.695 9.534 0.810

Interpretation¶

The Random Forest models improve substantially over the corresponding linear regression models. Using audio features alone, Random Forest achieves an R² of 0.585, compared with 0.444 for audio-only linear regression, indicating that non-linear relationships among audio characteristics provide additional predictive value.

The strongest performance is obtained when release year is added to the audio features. The Random Forest model achieves an MAE of 6.695, an RMSE of 9.534, and an R² of 0.810. This indicates that the model accounts for approximately 81% of the observed variation in song popularity within the randomly held-out test set. Because release year is a strong predictor in this dataset, this result should be interpreted alongside the later time-aware robustness analysis.

The improvement over the audio-only Random Forest further confirms that release year contains substantial predictive information. At the same time, the improvement over linear regression with the same feature set suggests that the relationship between popularity, release year, and audio characteristics is not purely linear.

7.5 Gradient Boosting Regression¶

Histogram-based Gradient Boosting is evaluated as an additional non-linear ensemble method. Unlike Random Forest, which builds many trees independently, boosting constructs trees sequentially, with each new tree improving upon errors made by the existing ensemble. The histogram-based implementation groups continuous feature values into discrete bins, improving computational efficiency for large datasets.

To maintain a consistent comparison, two versions are evaluated: one using only audio features and another combining audio features with release year.

Model MAE RMSE R²
0 HistGradient Boosting - Audio Only 10.816 14.151 0.581
1 HistGradient Boosting - Audio + Year 6.721 9.547 0.810

Interpretation¶

HistGradient Boosting substantially improves predictive performance when release year is included. The audio-only model achieves an R² of 0.581, whereas the audio-plus-year model reaches an R² of 0.810. At the same time, MAE decreases from 10.816 to 6.721 and RMSE decreases from 14.151 to 9.547.

The results closely match the performance of the Random Forest models. In particular, the audio-plus-year HistGradient Boosting model performs almost identically to the corresponding Random Forest model. Random Forest remains marginally better in terms of MAE and RMSE, although both models achieve an R² of approximately 0.810.

The consistency across two different non-linear ensemble methods strengthens the evidence that release year contains substantial predictive information and that non-linear relationships contribute to predicting song popularity.

Lower MAE and RMSE values indicate smaller prediction errors, while higher R² values indicate that a larger proportion of variation in song popularity is explained by the model.

Final Model Comparison and Selection¶

The final comparison shows that models incorporating release year consistently outperform their audio-only counterparts. This pattern is observed across Linear Regression, Random Forest, and HistGradient Boosting, confirming that temporal information contributes substantially to predictive performance.

The best-performing model is Random Forest with audio features and release year, achieving an MAE of 6.695, an RMSE of 9.534, and an R² of 0.810. This means that the model explains approximately 81% of the variation in popularity within the randomly held-out test set, while its predictions differ from observed popularity scores by approximately 6.7 points on average.

HistGradient Boosting with audio features and release year performs almost identically, with an R² of 0.810 and only slightly higher MAE and RMSE values. The close agreement between these two non-linear ensemble methods provides evidence that the strong predictive performance is not specific to a single algorithm.

Overall, the results indicate that audio characteristics contain meaningful predictive information, but release year is a dominant predictor in this dataset. Therefore, the Random Forest model using audio features and release year is selected as the best-performing model based on its lowest test-set MAE and RMSE.

7.7 Best Model Diagnostics¶

The Random Forest model using audio features and release year achieved the strongest overall test-set performance and is therefore examined in greater detail.

Two diagnostic views are used. First, observed popularity scores are compared with model predictions to assess how closely predictions align with actual values. Second, residuals are examined to identify systematic prediction errors, bias, and changes in error magnitude across the predicted popularity range.

Diagnostic Interpretation¶

The diagnostic plots show that the selected Random Forest model captures the overall relationship between the predictors and song popularity, but important limitations remain.

In the actual-versus-predicted plot, predictions generally increase with observed popularity, confirming that the model captures a substantial portion of the overall pattern. However, predictions are compressed toward the middle of the popularity range. Very highly popular songs are frequently underpredicted, while some tracks with observed popularity equal to zero receive substantially positive predictions. The dense vertical concentration at zero is particularly relevant because approximately 16.3% of tracks in the dataset have a popularity score of zero.

The residual plot also reveals non-random structure rather than a uniform cloud around zero. Residual dispersion changes across the prediction range, and visible boundary patterns indicate that errors are constrained by the bounded 0–100 target scale. Large positive and negative residuals remain present, showing that the model has difficulty with some extreme observations.

Therefore, although the selected Random Forest model achieves strong overall test-set performance with an R² of 0.810, its errors are not completely random or constant across the prediction range. The diagnostics suggest regression toward moderate popularity values and reduced accuracy for extreme and zero-popularity observations. These limitations should be considered when interpreting the model's predictive performance.

8. Discussion¶

This analysis investigated how well Spotify song popularity can be predicted from audio characteristics and release year. Across the exploratory and predictive stages, the results reveal a consistent pattern: audio features contain meaningful information about popularity, but temporal structure plays a substantially larger role.

The initial correlation analysis suggested relatively strong relationships between popularity and several audio characteristics. Energy and loudness showed positive associations with popularity, while acousticness and instrumentalness showed negative associations. However, these relationships changed considerably after accounting for release year. The year-adjusted correlations became much weaker, indicating that part of the apparent relationship between audio characteristics and popularity reflects broader historical changes in both musical characteristics and popularity scores.

This interpretation is reinforced by the predictive modeling results. The audio-only Linear Regression model achieved an R² of 0.444, demonstrating that audio characteristics alone contain meaningful predictive information. Non-linear ensemble models improved audio-only performance, with Random Forest reaching an R² of 0.585 and HistGradient Boosting reaching 0.581. These improvements suggest that relationships between musical characteristics and popularity are not purely linear.

The largest performance gains occurred when release year was added. Linear Regression improved to an R² of 0.759, while both Random Forest and HistGradient Boosting reached approximately 0.810. The selected Random Forest model achieved the lowest test-set errors, with an MAE of 6.695 and an RMSE of 9.534. Nevertheless, the feature-importance analysis showed that release year accounted for approximately 84.7% of the model's impurity-based importance, demonstrating that the model's strong predictive performance is driven primarily by temporal information rather than audio characteristics alone.

The diagnostic analysis also highlights important limitations. Predictions tend to be compressed toward moderate popularity values, with highly popular tracks often underpredicted and some zero-popularity tracks assigned substantially positive predictions. Residuals display non-random structure and changing dispersion across the prediction range. Therefore, the strong overall R² should not be interpreted as uniformly accurate prediction across all songs.

Overall, the findings suggest that song popularity in this dataset reflects a combination of musical characteristics and strong temporal structure. Audio features contribute predictive value, particularly through non-linear relationships, but release year is the dominant predictor. This result emphasizes the importance of controlling for temporal confounding when analyzing relationships between musical characteristics and platform-based popularity measures.

9. Limitations and Future Work¶

Several limitations should be considered when interpreting the results of this analysis.

First, the dataset is observational and does not support causal conclusions. Although release year and several audio characteristics are associated with popularity, the analysis cannot establish that these variables directly cause songs to become more or less popular.

Second, the popularity target is strongly structured by release year. The selected Random Forest model assigns approximately 84.7% of its impurity-based feature importance to year, and the predictive performance of all model families improves substantially when year is included. This suggests that the high test-set performance partly reflects temporal patterns in the dataset rather than musical characteristics alone.

Third, the analysis uses a random 80/20 train-test split. Because songs from similar historical periods can appear in both training and test sets, the reported metrics measure interpolation within a randomly held-out sample rather than genuine forecasting of popularity for future releases. A time-based validation strategy would provide a more demanding test of temporal generalization.

Fourth, approximately 16.3% of tracks have a popularity score of zero. These observations may represent genuinely unpopular tracks, catalog or measurement effects, or other platform-specific processes that cannot be distinguished using the available variables. The diagnostic plots indicate that the model has particular difficulty with this concentration of zero values.

Fifth, the predictor set is limited. Song popularity is influenced by many factors not represented in the analysis, including artist reputation, playlist placement, marketing exposure, social-media attention, genre, collaborations, label support, and broader cultural trends. Incorporating such variables could improve both predictive performance and substantive interpretation.

Finally, Random Forest impurity-based feature importance can be affected by feature characteristics and model structure. Future work could use permutation importance or SHAP-based explanations to provide a more robust assessment of predictor contributions.

Future research could extend this project by applying time-based validation, explicitly modeling zero-popularity tracks, incorporating artist- and genre-level information, tuning model hyperparameters through cross-validation, and evaluating additional algorithms. These extensions would help determine whether the observed predictive patterns generalize beyond the current randomly held-out test set.

10. Conclusion¶

This project investigated whether Spotify song popularity can be predicted from audio characteristics and release year using exploratory data analysis and machine learning. The analysis revealed a strong temporal structure in the dataset: popularity increases substantially for more recently released songs, with release year showing a correlation of approximately 0.86 with popularity.

The exploratory analysis also demonstrated why raw correlations between audio characteristics and popularity must be interpreted cautiously. Features such as energy, loudness, and acousticness initially showed moderate to strong associations with popularity. However, after adjusting for release year, these relationships became much weaker. This indicates that much of the apparent association between musical characteristics and popularity reflects broader historical changes in both music production and the dataset.

Predictive modeling confirmed these findings. The mean baseline produced an MAE of 18.56 and an RMSE of 21.88. Linear Regression using audio features alone improved performance to an R² of 0.444, while adding release year increased R² to 0.759. Non-linear ensemble methods performed better: the Random Forest model using audio features and year achieved the best overall performance, with an MAE of 6.695, RMSE of 9.534, and R² of 0.810. HistGradient Boosting produced nearly identical performance, with an R² of 0.810.

Model diagnostics showed that the selected Random Forest captures much of the overall structure in popularity but still exhibits systematic prediction errors, particularly around the large concentration of zero-popularity tracks and at the extremes of the target distribution. Feature importance further demonstrated the dominance of release year, which accounted for approximately 84.7% of the model's impurity-based importance.

Overall, the results suggest that Spotify popularity is predictable to a substantial degree within this dataset, but prediction is driven primarily by temporal structure rather than audio characteristics alone. Therefore, the project demonstrates both the value of machine learning for popularity prediction and the importance of careful interpretation when strong historical patterns are present in observational data.
